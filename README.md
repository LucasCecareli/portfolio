# 🚀 Portfólio de Ciência da Computação - Lucas Ribeiro

Portfólio web moderno, dinâmico e responsivo desenvolvido com as tecnologias mais recentes do ecossistema front-end para destacar certificações oficiais, projetos de engenharia de software e fundamentos acadêmicos.

---

## 🛠️ Tecnologias Utilizadas

- **[React 19](https://react.dev/)** + **[Vite 8](https://vite.dev/)** + **[TypeScript](https://www.typescriptlang.org/)**: Máximo desempenho, build instantâneo e tipagem segura.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Estilização ultra-rápida com variáveis CSS modernas e grid responsivo.
- **[Framer Motion](https://www.framer.com/motion/)**: Transições dinâmicas e animações fluidas.
- **[Lucide Icons](https://lucide.dev/)**: Ícones elegantes e otimizados.
- **[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)**: Efeito interativo de celebração ao copiar contatos.

---

## ✨ Recursos & Funcionalidades

1. **Terminal Interativo Integrado (CLI):**
   - Recurso visual de destaque para estudantes de Ciência da Computação.
   - Permite executar comandos reais como `about`, `skills`, `projects`, `certs`, `contact` ou clicar em atalhos rápidos.
2. **Seção de Certificações Oficiais:**
   - Cards dedicados com identificador de credencial (ID), competências validadas e botão de link oficial para verificação.
3. **Projetos em Destaque com Filtro Dinâmico:**
   - Filtro por categorias (*Full-Stack*, *Backend*, *IA / Dados*, *Sistemas / C++*).
   - Modal com detalhes de arquitetura, métricas de desempenho, link para o código no GitHub e demonstração ao vivo (*Live Demo*).
4. **Bento Grid de Fundamentos de Computação:**
   - Destaque para o curso no **Instituto Mauá de Tecnologia**, disciplinas de computação e números-chave.
5. **Contato Dinâmico:**
   - Botão interativo para copiar e-mail com efeito confetti e formulário direto.

## 📂 Como Personalizar Seus Dados

Todos os seus projetos, certificações, links e biografia estão centralizados em um único arquivo:

👉 **`src/data/portfolioData.ts`**

Para alterar um projeto ou adicionar uma nova certificação, basta editar esse arquivo! Não é necessário mexer nos componentes visuais.

---

## 💻 Como Rodar Localmente

1. No terminal do projeto, execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
2. Abra a URL exibida no navegador (geralmente `http://localhost:5173`).

## 🌐 Como Publicar na Internet (100% Gratuito)

### Opção Recomendada: Vercel

1. Crie um repositório no seu [GitHub](https://github.com/) e envie o código:
   ```bash
   git add .
   git commit -m "feat: portfolio inicial completo"
   git remote add origin https://github.com/SEU-USUARIO/portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. Acesse [vercel.com](https://vercel.com/) e faça login com seu GitHub.
3. Clique em **"Add New Project"**, selecione o repositório `portfolio` e clique em **"Deploy"**.
4. Em menos de 1 minuto, seu portfólio estará online com HTTPS gratuito e atualizações automáticas a cada commit!
